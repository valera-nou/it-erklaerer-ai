# IT-Erklärer AI

Ein smarter Assistent, der komplexe IT-Begriffe kurz und knackig erklärt inklusive passendem Code-Beispiel. 

##  Features
* **KI-basiert:** Nutzt die OpenAI API (GPT-4o-mini).
* **Direktes Feedback:** Erklärungen und Code-Beispiele im modernen Design.
* **Responsive:** Funktioniert im Browser auf dem Desktop und dem Smartphone.

##  Technologien
* **Backend:** Python & Flask
* **Frontend:** HTML & CSS 
* **KI:** OpenAI API

##  Installation & Start
1. Repository klonen oder Dateien herunterladen.
2. Abhängigkeiten installieren:
   terminal
   py -m pip install -r requirements.txt
